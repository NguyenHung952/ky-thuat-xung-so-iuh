# 📡 Kỹ thuật xung số – IUH

Kho tài liệu học tập môn **Kỹ thuật xung số** tại IUH.

- Chương 1 → Chương 5: Tài liệu học tập theo từng chương.

## 🎯 Mục đích

- Hệ thống hóa kiến thức về tín hiệu xung và mạch số.
- Hỗ trợ học tập, ôn thi và tra cứu nhanh theo chương.
- Làm nền tảng cho các môn mạch số, điện tử số và hệ thống nhúng.
